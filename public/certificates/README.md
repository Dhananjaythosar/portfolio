# Certificates

Place certificate PDFs or images here, for example:

- `aws-data-engineer-associate.pdf`
- `databricks-spark-associate.pdf`
- `aws-cloud-practitioner.pdf`

Then wire them in `src/data/profile.ts`:

```ts
certificateUrl: "/certificates/aws-data-engineer-associate.pdf",
verifyUrl: "https://...",
```
